Worker pool

How the tool schedules tasks across parallel workers.

Sizing the pool

The pool starts 4 workers by default. Set workers in the configuration file to change it.

Defaults by platform
PlatformWorkersNotes
Linux4Uses epoll
macOS4Uses kqueue | fallback
Windows2

Steps

  1. Measure the task duration.
  2. Pick a size:
    • CPU-bound: one worker per core
    • I/O-bound: two to four per core
  3. Restart the service.
# example.yaml
workers: 8
timeout: 30

Too many workers can slow things down.
